# Sagrada Biblia

Biblia católica (73 libros), protestante (66) y ortodoxa, en 22 traducciones y 16 idiomas. Sin anuncios.

- Versículos en párrafos, subtítulos y notas (Biblia Platense de Mons. Straubinger)
- Marcadores, resaltados, progreso de lectura y capítulos leídos
- Audio: lectura en voz alta con las voces del dispositivo
- Encíclicas papales (resumen + enlace a vatican.va) y apócrifos
- Funciona sin conexión

## Instalar
- **Android:** descargá `SagradaBiblia.apk` desde *Releases* y abrilo.
- **iPhone / computadora:** abrí la versión web (GitHub Pages) y elegí *Agregar a pantalla de inicio*.
